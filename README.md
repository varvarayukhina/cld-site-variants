# CLD — три варианта дизайна сайта (прототип)

Прототип нового сайта лаборатории CLD (Черкесск, lab.discript.ru). Не официальный сайт.

- `v1/` — «Поиск»: строка поиска и короткий список частых анализов.
- `v2/` — «Кнопки»: крупные кнопки по задачам.
- `v3/` — «Помощник»: сайт задаёт простые вопросы и подсказывает анализы.

Переключатель вариантов — полоса сверху, экран при переключении сохраняется.
Данные общие: `shared/cld-data.js` (цены пункта Черкесск, ул. Гутякулова, 20, на 22.10.2026).
Шрифты: Avanti CLD (лицензия у CLD есть; файлы восстановлены из брендбука 2022 — заменить оригиналами) и Montserrat (OFL).


## Актуальный вариант v4

`v4/` — основной прототип после обсуждений с лабораторией. Гид `#for-pregnant` использует общие цены выбранного пункта, доступность, карточки исследований и корзину v4.

Исходники утверждённого гида: `content/pregnancy-guide/page.html` (вёрстка/тексты), `calendar.js` (календарь и пояснения), `adapter.js` (подключение к приложению). Это исходники, не отдельная опубликованная версия сайта. Иллюстрации: `assets/img/pregnancy/`.

После правок гида выполнить:

```sh
python3 scripts/build-pregnancy-guide.py
```

Скрипт обновляет `v4/index.html` и изолированный `assets/pregnancy-guide.css`; повторная сборка идемпотентна. При сборке v4 из старой базы необходимо вызвать `integrate(html)` из этого скрипта перед записью результата, чтобы сохранить утверждённый гид.

GitHub Pages остаётся прототипом с `noindex`. SEO-публикация на рабочем домене требует отдельных индексируемых URL и подключения реальных сервисов лаборатории.

Общие заголовки/описания экранов и блоки перехода из прайса к гидам: `content/navigation/navigation.js`, стили — `assets/navigation.css`. После их изменения выполнить `python3 scripts/build-navigation.py`. Этот шаг также включён в локальную сборку v4 после сборки гида.

Women guide: `content/women-guide/` → `python3 scripts/build-women-guide.py`.
Comparisons: `content/comparisons/articles.json` and `adapter.js` → `python3 scripts/build-comparisons.py`; styles in `assets/comparisons.css`.
Children guide: `content/kids-guide/` → `python3 scripts/build-kids-guide.py`.
Parents and men: `content/audience-guides/` → `python3 scripts/build-audience-guides.py`.
Rebuild order: pregnancy → women → kids → audience → navigation → comparisons → catalog-additions → crosslinks → situations → prep → card-fixes. All builders are idempotent. Contextual comparisons use the shared catalogue, selected point and cart; source references stay in the JSON for editorial verification.

Audience guides women, kids, men and senior share one structure (03.11.2026): navy hero with an illustration (assets/img/{women/hero-character,kids/hero-family,men/hero,senior/hero}.webp), task grid «С какой задачей вы пришли?», all topic sections visible, sticky TOC on desktop (same component as the pregnancy guide), one optional «Подробнее» per topic, analyses at the end of each topic. No topic gating and no sources block on the page. Shared task/hero/readability styles live in `content/women-guide/style.css` and `content/audience-guides/style.css`; icon symbols are embedded in each guide.

Comparison articles: short fields (intro, items, use, preparation) feed the dialog; `situation`, `sections`, `details` (FAQ + FAQPage JSON-LD), `related` and `description` render on the full page `#compare-<key>`. Analysis cards link to every article that contains their code. Drafts and verification live in `~/cld-work/site/comparisons-new/`; merge with `python3 ~/cld-work/site/comparisons-new/merge.py <keys>` then rebuild.

Situation pages «Анализы по поводу» (#povody, #povod-<id>): `content/situations/situations.json` → `python3 scripts/build-situations.py`; illustrations in `assets/img/situations/`; facts and primary-source review in `~/cld-work/situations-facts.md`.

Card cross-links («Читайте также»: audience guides and checkups containing the analysis): `python3 scripts/build-crosslinks.py`, last in the order.

New analyses (catalogue entry, per-point prices, category, card): `content/catalog-additions/*.json` → `python3 scripts/build-catalog-additions.py`. Data is generated by `~/cld-work/cards-b1/to_site.py` only for codes in `approved.txt` (verified and already written to the cards spreadsheet).

Card text fixes from the external review (05.11.2026): `content/card-fixes/rules.json` (global wording rules + per-code replacements, every content edit checked against primary sources) → `scripts/build-card-fixes.py`, always last in the order; it patches CARDS and the catalogue descriptions at runtime.

Preparation guide «Как подготовиться к анализам» (#podgotovka): comic-style page from `content/prep-guide/prep.json` → `scripts/build-prep.py` (after situations, before card-fixes); illustrations in `assets/img/prep/` (Codex, sources in ~/cld-work/site/img-src/gen-prep/). Linked from every card's «Как подготовиться» block, the order memo and the footer. Facts: CLD's МИС preparation codes + ГОСТ Р 59778-2021, ГОСТ Р 53079.4-2008, clinical guidelines; independent review in ~/cld-work/prep-guide-verify.md.
